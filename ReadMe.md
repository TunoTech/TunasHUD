# TunasHUD

## Description

TunasHUD is a lightweight, 100% server-side Minecraft Paper plugin that provides a scrolling compass and player biome information without requiring client-side mods or resource packs.

**Features:**
- Real-time scrolling compass displayed at the top of the screen.
- Eight cardinal and intercardinal directions with yellow highlighting for the current heading.
- Player biome names displayed alongside player names in the Tab player list.
- Automatic HUD activation when joining the server.
- No client-side installation required.

## Commands

| Command | Description |
|---|---|
| `/hud` | Display available commands. |
| `/hud on` | Show the compass. |
| `/hud off` | Hide the compass. |
| `/hud help` | Display help information. |

**Note:** Press Tab to view online players and their current biomes. Compass visibility resets when disconnecting.

## Installation

1. Download the latest TunasHUD `.jar` file.
2. Place the JAR into your Minecraft Paper server's `plugins` folder.
3. Restart the server.
4. Join the server. TunasHUD automatically activates.

No additional dependencies, client-side mods, or resource packs are required.
