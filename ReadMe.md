# TunasHUD

## Description

TunasHUD is a lightweight, 100% server-side Minecraft Paper plugin that provides a real-time scrolling compass, bed-spawn waypoint, Minecraft clock, and player biome information without requiring client-side mods or resource packs.

It's simple, straight to the point, and 100% made with the help of AI.

Built for Minecraft 26.3

**Features:**
- **Scrolling Compass**: Real-time compass displayed at the top of the screen, featuring eight cardinal and intercardinal directions, and yellow highlighting for the current heading.

- **Bed-Spawn Waypoint**: A green house symbol (⌂) points toward your personal bed-spawn location on the compass.  *Bed must be registered.

- **Minecraft Clock**: Displays the current in-game time in 24-hour format (HH:mm) in the Tab player-list header.

- **Day/Night Indicators**: A sun (☀) or crescent moon (☾) appears next to the clock depending on the Minecraft server time.

- **Biome Information**: Displays each player's current biome beside their name in the Tab player list, updating automatically as they explore.

- **Automatic Activation**: The compass activates when joining the server.

- **Server-Side Only**: No client-side installation, additional mods, nor resource packs required.  Should not interfere with applied resource packs.

## User Commands

| Command | Description |
|---|---|
| `/hud` | Display available commands. |
| `/hud on` | Show the compass. |
| `/hud off` | Hide the compass. |
| `/hud help` | Display help information. |

**Note:** Press Tab to view online players and their current biomes. Compass visibility resets when disconnecting.

## Installation

1. Download the latest TunasHUD `.jar` file.
2. Place the JAR into your Minecraft Paper server's `plugins` folder.
3. Restart the server.
4. Join the server. TunasHUD automatically activates.

No additional dependencies, client-side mods, or resource packs are required.

This is a personal, fun to learn, project that does not come with any support.
